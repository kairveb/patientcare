# Deployment environment values

This guide covers the deployment settings in `.env.production.example` and the feature overrides in `.env.example`. `REQUIRED` means required for a working production deployment or for the selected feature; `RECOMMENDED` is a production safety/reliability choice; `OPTIONAL` is needed only for a corresponding override or integration.

**Secrets belong in the hosting provider's environment settings or the server's private `.env` file, never in Git or the Docker image.** Keep `APP_KEY` stable across releases. Do not copy real credentials into these examples.

| Variable(s) | Status | What it does | Where to obtain the value | Secret? | What breaks if missing or wrong |
|---|---|---|---|---|---|
| `APP_NAME` | OPTIONAL | Display name and default mail name. | Project owner/team. | No | Labels may use a framework default. |
| `APP_ENV`, `APP_DEBUG` | REQUIRED | Select production behavior and suppress debug pages. | Set to `production` and `false` for production. | No | Wrong environment/debug settings can expose details or bypass production-only behavior. |
| `APP_KEY` | REQUIRED | Encrypts Laravel-encrypted values and signed data. | Generate once with `php artisan key:generate`; store with deployment secrets. | **Yes** | Encryption, sessions, and signatures fail; rotating it can invalidate previously encrypted data. |
| `APP_URL` | REQUIRED | Canonical URL for generated links. | Public HTTPS domain from the project/domain owner. | No | Links can use the wrong host or scheme. |
| `APP_TIMEZONE` | REQUIRED | Application and scheduler timezone. | Hospital/project owner; this project uses `Asia/Manila`. | No | Times and scheduled tasks can be interpreted in the wrong timezone. |
| `APP_LOCALE`, `APP_FALLBACK_LOCALE`, `APP_FAKER_LOCALE` | OPTIONAL | Locale defaults. | Project owner; default to `en`, `en`, `en_US`. | No | Framework defaults are used. |
| `APP_MAINTENANCE_DRIVER`, `APP_MAINTENANCE_STORE` | OPTIONAL | Maintenance-mode state storage. | Choose `file` or shared database/cache based on hosting topology. | No | Maintenance mode may not be shared consistently across instances. |
| `APP_PREVIOUS_KEYS` | OPTIONAL | Supports a planned encryption-key rotation. | Security/operator-managed prior key list. | **Yes** | Old encrypted values may not be decryptable during a key rotation. |
| `TRUSTED_PROXIES` | REQUIRED behind a proxy | Lets Laravel safely interpret forwarded HTTPS/host information. | **Must match the hosting provider's exact proxy addresses/CIDRs.** | No | HTTPS redirects may loop, and secure URLs/cookies may be wrong. Never trust guessed or arbitrary proxies. |
| `CORS_ALLOWED_ORIGINS` | OPTIONAL | Exact browser origins permitted for cross-origin requests. | Frontend owner; include scheme and optional port. | No | Cross-origin browser requests are rejected; same-origin requests do not need it. |
| `SANCTUM_STATEFUL_DOMAINS` | OPTIONAL | Hosts for cookie-authenticated first-party API requests. | Frontend/public domain owner; host only, no scheme/path. | No | First-party API requests may not be treated as stateful. |
| `DB_CONNECTION` | REQUIRED | Selects the database driver (`mysql` or `mariadb`). | Hosting database panel. | No | Laravel selects the wrong database connector. |
| `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD` | REQUIRED | Database endpoint, schema, and app credentials. | Hosting database panel; use a least-privilege app user. | Password: **Yes**; others: No | The application cannot connect or lacks required schema permissions. |
| `DB_URL`, `DB_SOCKET`, `DB_CHARSET`, `DB_COLLATION` | OPTIONAL | MySQL connection URL/socket or encoding overrides; explicit URL/socket may supersede ordinary host fields. | Database provider; normally leave URL/socket blank and use `utf8mb4`. | URL may contain **secrets** | Wrong overrides can prevent connection or cause character-set problems. |
| `MYSQL_ATTR_SSL_CA` | OPTIONAL | MySQL TLS CA certificate path when the provider requires it. | Hosting database TLS documentation/support. | No | TLS connections can fail certificate validation. |
| `SESSION_DRIVER` | REQUIRED | Session persistence backend; production example uses `database`. | Choose a migrated database-backed or supported shared store. | No | Login sessions fail or are lost on ephemeral file storage. |
| `SESSION_LIFETIME`, `SESSION_CONNECTION`, `SESSION_TABLE`, `SESSION_STORE`, `SESSION_COOKIE`, `SESSION_PATH`, `SESSION_DOMAIN`, `SESSION_PARTITIONED_COOKIE` | OPTIONAL | Session expiry, backend overrides, and cookie scope. | Project/domain owner; use defaults unless a custom table/connection or cookie scope is required. | No | Incorrect overrides can prevent session persistence or login. |
| `SESSION_ENCRYPT`, `SESSION_SECURE_COOKIE`, `SESSION_HTTP_ONLY`, `SESSION_SAME_SITE` | RECOMMENDED | Session data/cookie protections; secure cookie should be true on HTTPS. | Set according to production HTTPS and browser topology. | No | Weaker session protection or cookies not sent correctly. |
| `SESSION_IDLE_MINUTES`, `INACTIVITY_ENABLED` | RECOMMENDED | Authenticated-user inactivity timeout. | Approved security/session policy; timeout is in minutes. | No | App defaults apply; an obsolete `INACTIVITY_TIMEOUT` variable is ignored. |
| `OTP_ENABLED`, `OTP_TTL_MINUTES`, `OTP_MAX_ATTEMPTS`, `OTP_MAX_RESENDS`, `OTP_MAX_SENDS`, `OTP_RESEND_COOLDOWN_SECONDS` | OTP switch REQUIRED if used; limits RECOMMENDED | Controls OTP delivery and throttling behavior. | Approved authentication policy and mail provider capability. | No | OTP delivery/expiry/limits behave incorrectly; enabled OTP with a log mailer cannot reach users. |
| `LOGIN_MAX_ATTEMPTS`, `LOGIN_LOCKOUT_MINUTES` | RECOMMENDED | Configures login attempt and lockout thresholds. | Approved security policy. | No | Default security limits apply. |
| `QUEUE_CONNECTION` | REQUIRED for queued reminders | Stores queued jobs; production example uses the database queue. | Use the migrated database or a supported queue provider. | No | Jobs cannot be queued/processed; database queue needs a worker. |
| `DB_QUEUE_CONNECTION`, `DB_QUEUE_TABLE`, `DB_QUEUE`, `DB_QUEUE_RETRY_AFTER`, `QUEUE_FAILED_DRIVER` | OPTIONAL | Database queue table, connection, retry timing, and failed-job storage overrides. | App operator; defaults are suitable for the standard database queue. | No | Invalid overrides can prevent jobs from queuing/retrying. |
| `CACHE_STORE`, `CACHE_PREFIX` | RECOMMENDED | Shared cache/lock backend and namespace. | Hosting provider/database or cache service; use unique prefix. | No | Cache-backed features/locks can fail or collide; local cache is ephemeral. |
| `DB_CACHE_CONNECTION`, `DB_CACHE_TABLE`, `DB_CACHE_LOCK_CONNECTION`, `DB_CACHE_LOCK_TABLE` | OPTIONAL | Database cache backend/lock overrides. | App operator/database host; defaults normally suffice. | No | Incorrect overrides can prevent cache/lock operations. |
| `BROADCAST_CONNECTION` | REQUIRED for the supplied container setup | Selects broadcast driver; use `null` because the image does not run Reverb. | Set `null`; choose `reverb` only with a separately configured WebSocket service. | No | Broadcast events fail if configured for an unavailable Reverb server. |
| `MAIL_MAILER`, `MAIL_HOST`, `MAIL_PORT`, `MAIL_SCHEME`, `MAIL_USERNAME`, `MAIL_PASSWORD`, `MAIL_FROM_ADDRESS`, `MAIL_FROM_NAME` | REQUIRED when OTP/email is enabled | SMTP transport and authorized sender. | Email provider's SMTP configuration page and verified sender settings. | Password: **Yes**; username may be sensitive | OTP, verification, password reset, and reminders may not deliver. |
| `MAIL_URL`, `MAIL_EHLO_DOMAIN`, `MAIL_ENCRYPTION`, `MAIL_SENDMAIL_PATH`, `MAIL_LOG_CHANNEL`, `POSTMARK_API_KEY`, `RESEND_API_KEY` | OPTIONAL | Mail transport URL/identity, legacy encryption setting, sendmail/log overrides, or provider API credentials. | Selected provider's mail settings or server administrator. | URL/API keys may contain **secrets** | Only the corresponding mail transport/override fails. |
| `FILESYSTEM_DISK` | REQUIRED | Selects default file storage. Use `s3` on ephemeral PaaS or `local` with a persistent mount. | Choose according to hosting/storage architecture. | No | Uploads may be written to a non-durable local filesystem. |
| `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_DEFAULT_REGION`, `AWS_BUCKET`, `AWS_ENDPOINT`, `AWS_URL`, `AWS_USE_PATH_STYLE_ENDPOINT` | Required only when `FILESYSTEM_DISK=s3`; otherwise OPTIONAL | Configures S3-compatible file storage. | Object-storage control panel; endpoint/region/bucket and scoped access credentials. | Access key/secret: **Yes** | Upload/download operations fail or target the wrong bucket/endpoint. Provider photos currently use the local public disk even with S3 selected. |
| `LOG_CHANNEL`, `LOG_LEVEL`, `LOG_DEPRECATIONS_CHANNEL` | RECOMMENDED | Send production logs to host collection and set appropriate verbosity. | Hosting log platform; production example uses `stderr`. | No | Logs may be lost on redeploy or expose excessive detail. |
| `LOG_STACK` | OPTIONAL | Selects channels used by the `stack` logger. | App operator; relevant only with `LOG_CHANNEL=stack`. | No | Stack channel may use its default file logger. |
| `DB_BACKUP_ENABLED` | RECOMMENDED | Toggles scheduled local database dumps. | Set false when using managed database backups; otherwise confirm backup client and durable destination. | No | Local scheduled dump may fail or be lost with ephemeral storage. |
| `AI_PROVIDER`, `AI_TIMEOUT`, `AI_RETRIES` | OPTIONAL | Selects rules/Gemini/OpenAI triage integration and request limits. | Project owner; rules is the default/no-key option. | No | A configured remote provider may fail; rules mode does not need a remote key. |
| `AI_SEND_AGE_SEX` | RECOMMENDED | Controls whether age/sex context is sent to AI provider. | Privacy/data-minimization decision from the project/privacy owner. | No | The default may disclose more context to an external provider than intended. |
| `GEMINI_API_KEY`, `GEMINI_MODEL` | Required only for Gemini; otherwise OPTIONAL | Gemini credential and model selection. | Google AI Studio; use a currently supported model. | API key: **Yes** | Gemini requests fail if the provider is selected without a valid key/model. |
| `OPENAI_API_KEY`, `OPENAI_MODEL` | Required only for OpenAI; otherwise OPTIONAL | OpenAI credential and model selection. | OpenAI platform account/project settings. | API key: **Yes** | OpenAI requests fail if selected without a valid key/model. |
| `TELEHEALTH_PROVIDER` | OPTIONAL; required for a working telehealth integration | Selects `zoom` or explicitly opted-in demo-only `jitsi_demo`. | Project owner and telehealth deployment decision. | No | Telehealth session creation/join is unavailable without a configured provider. |
| `TELEHEALTH_JOIN_EARLY_MINUTES`, `TELEHEALTH_JOIN_LATE_MINUTES` | OPTIONAL | Defines the join time window. | Approved telehealth workflow. | No | Application defaults are used. |
| `ZOOM_ENABLED`, `ZOOM_ACCOUNT_ID`, `ZOOM_CLIENT_ID`, `ZOOM_CLIENT_SECRET` | Required only for Zoom; otherwise OPTIONAL | Enables Zoom integration and its service credentials. | Zoom Marketplace app/account. | Client secret: **Yes**; other IDs: No | Zoom meeting creation fails when enabled without valid credentials. |
| `DPO_NAME`, `DPO_EMAIL`, `DPO_PHONE` | RECOMMENDED (deployment preflight warns when incomplete) | Privacy contact details. | Person/team responsible for privacy/legal review. | Usually no; use private deployment config | Preflight warns and displayed privacy contact details are incomplete. |
| `PRIVACY_NOTICE_VERSION`, `TERMS_VERSION`, `PRIVACY_EFFECTIVE_DATE` | RECOMMENDED | Version/date labels used for consent records. | Person/team responsible for approved notice and terms. | No | Defaults or stale consent versions may be recorded. |
| `REPORT_PASSWORD_CONFIRM_MINUTES` | OPTIONAL | Duration of recent password confirmation for reports. | Approved security policy. | No | Application default is used. |
| `APPOINTMENT_REASSIGNMENT_WINDOW_DAYS`, `APPOINTMENT_FULLY_BOOKED_WINDOW_DAYS`, `APPOINTMENT_REQUIRES_APPROVAL` | OPTIONAL | Appointment reassignment/booking workflow settings. | Person/team responsible for approved appointment workflow. | No | Application defaults apply, which may not match the intended workflow. |

`GEMINI_ENABLED` and `INACTIVITY_TIMEOUT` are not read by the current application configuration and should not be set. `GEMINI_MODEL` defaults to `gemini-3.6-flash` in the current config; verify model availability with Google AI Studio before enabling a remote AI provider.
